# Sargas Trapzors

Region-based traps for Foundry VTT: movement triggers, GM-confirmed effects and optional detection.

**Status:** pre-alpha / in development. Not ready for use.

**Compatibility:** Foundry VTT v14 only.

## Tests

The pure logic in `scripts/core/` is tested with the built-in Node test runner (no dependencies):

```
npm test
# or
node --test "tests/**/*.test.js"
```
